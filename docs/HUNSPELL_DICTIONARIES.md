# Офлайн-словари Hunspell

SmartInput умеет использовать локальные пары `*.dic` + `*.aff`. При наличии
обеих пар в `%LOCALAPPDATA%\SmartInput\Dictionaries` они загружаются автоматически:

- `ru_RU.dic` + `ru_RU.aff` — русский язык;
- `en_US.dic` + `en_US.aff` — английский язык.

Установка выполняется только по явному запуску:

```powershell
& "C:\Users\shuly\Desktop\Автоматический Т9 на комп\tools\InstallHunspellDictionaries.ps1"
```

Скрипт скачивает файлы во временную папку, проверяет минимальный размер,
атомарно переносит их в каталог SmartInput и сохраняет ссылки на лицензии.
Обычная работа приложения после этого полностью офлайн: сетевых запросов для
проверки или исправления текста нет.

Источники словарей:

- русский: [Goudron/ru-spelling-dictionary](https://github.com/Goudron/ru-spelling-dictionary), MPL 2.0;
- английский: [facelessuser/hunspell-en-us](https://github.com/facelessuser/hunspell-en-us),
  README содержит условия SCOWL/Ispell.

Пары не встраиваются в исходный репозиторий и не скачиваются при запуске,
чтобы не увеличивать установщик и не создавать скрытую сетевую зависимость.

## Важно о текущем этапе

Провайдер Hunspell уже изолированно подключён и протестирован, но пока не
заменяет боевой автоматический корректор. Сначала нужно сравнить его выдачу с
текущими правилами на реальном корпусе и сохранить защиту URL, путей,
идентификаторов, защищённых полей и Safe Mode. После этого можно включать его
как отдельный режим или безопасный fallback.

Для такого сравнения в Core есть `SpellEngineComparisonService`. Он принимает
поток тестовых слов, но возвращает только числа: количество кандидатов,
ожиданий, расхождений, проверенных точных слов, защищённых токенов и время
работы. Исходные слова не сохраняются в результате и не предназначены для
логирования.

Кандидат проверяется выбранным внешним словарём, а не только старым стартовым
списком. Поэтому после установки полного Hunspell новые словоформы и редкие
формы не будут отбрасываться только из-за отсутствия в прежнем словаре.

В DI зарегистрирован составной провайдер: SymSpell отвечает за быстрый поиск и
частотный порядок, Hunspell — за дополнительные словоформы. При совпадении
кандидатов остаётся один вариант с лучшим расстоянием и частотой.
