# Smart Input Core — короткая передача модели

Текущий результат Smart Input Core принят для следующего этапа.

## Критерий текущего этапа

Точность на word-level stress corpus: **89,74%**.
Этого достаточно для передачи в текущую нейронную модель; повышать процент прямо сейчас не требуется.

Подтверждено:

- 506 уникальных однокомпонентных тестов;
- 376 корректных применений из 419 исправляемых случаев;
- 0 неверных применений;
- 77/77 preserve-кейсов сохранены;
- 10/10 неоднозначных кейсов оставлены без автоприменения;
- обычные регрессии: 1340/1340;
- keyboard stress: 3/3;
- Release-сборки Core, WordProbe и ResidentHost успешны.

## Контракт для нейронной модели

Модель может оценивать:

1. является ли токен ошибочным;
2. какой вариант предложить;
3. confidence.

Финальные правила безопасности остаются в Rust/C#-ядре:

- `Candidate`, `Wait`, `NoChange` нельзя подменять произвольной логикой модели;
- сомнительные токены, бренды, аббревиатуры, модели, URL, email, пути и код сохраняются;
- при сомнении выбирается `Wait` или `NoChange`;
- двойной Shift остаётся детерминированной командой ядра;
- UI и live replacement не изменялись и не подключались к Rust.

## Важно для интеграции

Не переписывать текущую рабочую архитектуру и не превращать модель в единственный источник решения. Использовать модель как дополнительный локальный scorer/candidate provider поверх существующих защитных gate-правил.

Известные 43 пропуска в stress corpus допустимы на этом этапе и не являются основанием ослаблять safety thresholds.

## Ответы на вопросы интеграции

1. Сейчас подключается не ONNX-модель. В этой папке проверен локальный provider/evaluator из `SmartInput.Core`: SymSpell, Hunspell и встроенные RU/EN-частотные словари. Подключаемой Rust-модели, `.onnx` или `.safetensors` в переданном проекте нет. Отдельную нейронную модель можно добавить позже через provider-контракт.

2. Внутренний provider может вернуть ограниченный список кандидатов, но финальный ответ ядра — один результат: `ReplacementToken?`, `ConfidenceScore`, `Decision` (`apply`, `wait`, `no_change`) и `Kind`. Safety-gates ядра имеют приоритет над confidence модели.

3. Минимальный вход: токен и определённый ядром язык токена. Через portable adapter дополнительно доступны флаги layout/autocorrect, dominant language и агрегированные счётчики контекста: количество RU/EN токенов, количество токенов и символов контекста. Сырые предыдущие слова передавать не нужно. Layout image и edit-operation вычисляются ядром, а не требуются модели.

4. Ограничение 30–40 МБ остаётся целевым production-ориентиром, но не блокирует текущую передачу. Текущий стресс-прогон показал рабочий набор около 419 МБ после загрузки словарей; для достижения 30–40 МБ позже понадобятся mmap/FST и более компактная загрузка ресурсов.
